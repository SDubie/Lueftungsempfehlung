# Code of Conduct

## Our Pledge

We aim to make participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Stay on topic and keep feedback focused on the code or documentation.
- Assume good intent when reviewing changes.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Trolling, insulting comments, or deliberate disruption
- Publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject contributions that do not follow this code of conduct.
